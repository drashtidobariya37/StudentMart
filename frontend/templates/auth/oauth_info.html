Google Sign-In Configuration

Student Mart enforces official OpenID Connect protocol standards and never simulates or fakes unverified Gmail logins.

Status: Google OAuth 2.0 credentials (GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET) are not currently configured in your local .env file.

How to enable Google OAuth for this project:

  1. Go to the Google Cloud Console.
  2. Create a project and configure the OAuth Consent Screen.
  3. Create an OAuth 2.0 Client ID (Application type: Web application).
  4. Add Authorized Redirect URI: http://127.0.0.1:5000/auth/google/callback.
  5. Copy the generated Client ID and Client Secret into your project's .env file: 
    GOOGLE_CLIENT_ID=your_client_id_here.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_client_secret_here
  6. Restart the Flask server. The Google Sign-In button will instantly connect to Google's live OpenID servers.
